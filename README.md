# Calliope 2

Personal music streaming service. See `CLAUDE.md` for full architecture details.

## Starting and stopping

```bash
docker compose up -d        # start in background
docker compose down         # stop (data preserved)
docker compose down -v      # stop and wipe database
docker compose logs -f api  # tail API logs
docker compose logs -f db   # tail Postgres logs
```

## Database

### Connect with psql

```bash
docker compose exec db psql -U calliope
```

### Useful queries

```sql
-- Counts
SELECT
  (SELECT count(*) FROM artists) AS artists,
  (SELECT count(*) FROM albums)  AS albums,
  (SELECT count(*) FROM tracks)  AS tracks,
  (SELECT count(*) FROM genres)  AS genres;

-- Browse artists
SELECT id, name FROM artists ORDER BY name LIMIT 20;

-- Albums for an artist
SELECT al.id, al.title, al.year
FROM albums al
JOIN artists ar ON ar.id = al.artist_id
WHERE ar.name ILIKE '%radiohead%';

-- Tracks on an album (with duration)
SELECT t.track_number, t.title,
       (t.duration_ms / 1000 / 60) || 'm ' || (t.duration_ms / 1000 % 60) || 's' AS duration
FROM tracks t
JOIN albums al ON al.id = t.album_id
WHERE al.title ILIKE '%ok computer%'
ORDER BY t.track_number;

-- Tracks missing duration or cover art
SELECT t.title, t.file_path
FROM tracks t WHERE t.duration_ms IS NULL;

SELECT al.title, al.cover_art_path
FROM albums al WHERE al.cover_art_path IS NULL;

-- All genres and track counts
SELECT g.name, count(tg.track_id) AS tracks
FROM genres g
JOIN track_genres tg ON tg.genre_id = g.id
GROUP BY g.name ORDER BY tracks DESC;
```

### Rescan the music library

```bash
docker compose exec api python scripts/scan.py
```

Safe to re-run at any time — fully idempotent.

### Run migrations after schema changes

```bash
docker compose exec api alembic upgrade head
```

## API

Base URL: `http://localhost:8000` (or via nginx proxy at `/api/`)

Health check:
```bash
curl http://localhost:8000/health
```

Docs (auto-generated by FastAPI):
```
http://localhost:8000/docs
```

Key endpoints:
```
GET  /artists
GET  /artists/{id}/albums
GET  /albums/{id}
GET  /albums/{id}/art
GET  /tracks/{id}/stream      # supports byte-range
GET  /genres
GET  /search?q=
GET  /playlists
POST /playlists
```

## Project layout

```
api/        FastAPI app, Dockerfile, Alembic migrations
web/        React + Vite frontend (Phase 4)
android/    Kotlin Android app (Phase 5)
nginx/      nginx location block config
scripts/    (scan.py now lives in api/scripts/)
```

## Environment

Copy `.env.example` to `.env` and fill in values before first boot:

```bash
cp .env.example .env
```

Required vars: `DB_PASSWORD`, `SECRET_KEY`, `MUSIC_ROOT` (defaults to `/music` inside container).
