### Infra: Fix Docker container writing root-owned files

The `api` container ran as root, so any files it wrote to the music volume (`/backup/calliope/music/` → `/music`) were owned by root on the host, making them unmovable without sudo.

**Fix:** Added `user: "1000:1000"` to the `api` service in `docker-compose.yml`. No rebuild required — container recreated via `docker compose up -d api`. All future writes (album art, imported files) will be owned by `gray`.

**Committed & pushed:** `infra: run api container as host user to fix root-owned file writes`

Also bundled: a pre-existing change in `import_music.py` that sanitizes `/` characters in Amazon track filenames (`.replace("/", "-")`).

### Maintenance: Purity Ring disc 2 track ordering

The self-titled "purity ring" album had two bonus/remix tracks stored in the same flat folder as the main album, named `(Disc 2) 01 - ...` and `(Disc 2) 02 - ...`. The scanner parsed `01` and `02` as track numbers, causing them to sort to the top and collide with real tracks 1 and 2.

**Fix applied:**
- Renamed files on disk to `14 - ...` and `15 - ...` (continuing after 13 main tracks)
- Updated `track_number` and `file_path` in DB for track ids 3323 and 3324
