### Search History
migration 0005. UNIQUE(user_id, entity_type, entity_id). Upsert + prune to 10. Chip grid
on SearchPage above the search form.

### Similarity Engine + Radio Mode (migration 0006)
Separate indexer Docker container (port 8001). 38-dim vector: 13 MFCC mean + 13 MFCC var + 12 chroma mean.
Incremental by mtime. z-score norm params recomputed after each batch.
GET /tracks/{id}/similar: brute-force numpy (not pgvector ANN) — fast enough at ~3k tracks.
Radio mode in PlayerContext: _extendWithRadio() fires on queue empty + skipNext at end of queue.
Scanner is now two-phase: scan.py → indexer.

### Web-Based Music Import
POST /import/upload. Bandcamp: flat zip, Artist - Album.zip naming.
Amazon: two-level subdirectory, __ decoded to / in names.
nginx: client_max_body_size 600M + proxy_read_timeout 120s.

### Compilation Albums (migration 0007)
albumartist tag support in scanner. Various Artists treated as a special artist (excluded from
GET /artists results). track_artist + track_artist_id columns on tracks.
CompilationsPage, "Appears On" on ArtistPage, Artist column on AlbumPage for VA tracks.
tag_compilations.py script (host-side, mutagen) stamps albumartist on existing files.

### Now Playing Page
/now-playing route. Two-column: large art + controls | queue context (2 past, 2 ahead).
Similar tracks section (limit=5, hidden if not indexed). Animated equalizer.
PlayerContext: history state added (most-recent-first, cap 10). queue + queueIndex exposed.
PlayerBar: art thumbnail → /now-playing. Calliope nav brand → /now-playing.

### Dynamic Color Theme
node-vibrant v4. Three CSS variable tiers (--accent, --accent-hover, --accent2, --accent-dim).
JS sRGB animation via requestAnimationFrame (500ms ease-in-out).
CSS @property approach scrapped: Chromium interpolates @property <color> in OKLab — causes
washed-out midpoint flash on hue shifts between high-chroma complementary colors.

### Spacebar Play/Pause
useSpacebarPlayback() global listener in Layout. useRegisterFirstTrack() for page-specific
first-track callbacks (AlbumPage, ArtistPage, PlaylistPage). isPlaying initial state changed
null (nothing loaded) vs false (paused).

### Track Share Links (AlbumPage only)
?play={trackId}&note={artist}_{album}. Deep link: scroll row, attempt autoplay, ▶ Play fallback.
RequireAuth preserves ?redirect= through login. Playlist share links deferred to permissions PRD.

## Key Decisions

- pgvector/pgvector:pg16 image instead of stock postgres:16 (lacks vector extension)
- passlib dropped — incompatible with bcrypt 4.x; use bcrypt directly
- Brute-force numpy for similarity (not pgvector ANN) — adequate at current scale
- Two-phase scanner: scan.py subprocess + indexer HTTP call
- Music volume mounted read-write (album art upload writes Folder.jpg)
- Vibrant.js JS animation (not CSS @property) — OKLab interpolation causes color flash
- isPlaying: null = nothing loaded, false = paused (changed from false → null for spacebar logic)
