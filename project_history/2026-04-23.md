### Similarity Engine + Radio Mode (migration 0006)
Separate indexer Docker container (port 8001). 38-dim vector: 13 MFCC mean + 13 MFCC var + 12 chroma mean.
Incremental by mtime. z-score norm params recomputed after each batch.
GET /tracks/{id}/similar: brute-force numpy (not pgvector ANN) — fast enough at ~3k tracks.
Radio mode in PlayerContext: _extendWithRadio() fires on queue empty + skipNext at end of queue.
Scanner is now two-phase: scan.py → indexer.

## Key Decisions

- pgvector/pgvector:pg16 image instead of stock postgres:16 (lacks vector extension)
- passlib dropped — incompatible with bcrypt 4.x; use bcrypt directly
- Brute-force numpy for similarity (not pgvector ANN) — adequate at current scale
- Two-phase scanner: scan.py subprocess + indexer HTTP call
- Music volume mounted read-write (album art upload writes Folder.jpg)
- Vibrant.js JS animation (not CSS @property) — OKLab interpolation causes color flash
- isPlaying: null = nothing loaded, false = paused (changed from false → null for spacebar logic)
